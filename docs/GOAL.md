# Goal: vibestats as the Claude Code Identity Loop

vibestats should become the thing Claude Code users share when they want to say:

> this is how I build with Claude Code. How do you compare?

The product is not analytics for its own sake. It is an identity credential that turns a private `/insights` file into a public, privacy-preserving social object.

## North Star

A Claude Code user signs in, saves a derived profile, shares `/u/<gh-handle>`, and every recipient has an obvious next action: compare, claim their own profile, or come back later to see what changed.

## The Viral Loop

1. **Vanity:** the archetype card makes the user feel seen.
2. **Identity:** `/u/<gh-handle>` makes that result permanent and credible.
3. **Asymmetry:** profile visitors do not hit a dead end; they see "compare with @handle."
4. **Creation:** comparison requires either a saved profile or one upload, creating another profile candidate.
5. **Return:** evolution history, rarity, and weekly digest make the profile worth revisiting.

## Execution Order

1. **Make Wave 1 launchable.** OAuth, Neon, profile saves, settings, export/delete, and the raw-JSON privacy boundary must be boring and reliable.
2. **Make every profile share productive.** A shared profile should pull the recipient into instant comparison if logged in, or upload-to-compare if new.
3. **Make the share copy asymmetric.** "See how you'd pair with me" beats "look at my card."
4. **Add scarcity only after identity works.** Rare combos, sub-archetypes, and weekly leaderboards need persistent profiles first.
5. **Add retention last but early enough.** Weekly digest is the first real return lever; it should summarize evolution, rarity, and rank.

## Do Not Drift

- Do not add a 9th archetype.
- Do not upload raw insights JSON.
- Do not build in-app DMs.
- Do not build swipe matching.
- Do not add tokens, XP, or generic gamification.
- Do not make the directory before profiles and comparisons are good.

The killer version is simple: "I am an Orchestrator. You are a Sprinter. We'd be a Blitz Commander pair. Claim yours."
